# Laravel Students Manager

A Laravel web application to store and display students' data along with their posts, with full CRUD operations.

## Features
- Add, view, edit, and delete students
- Display each student's posts
- Full CRUD operations on students and posts

## Tech Stack
Laravel · PHP · MySQL · Blade · HTML · CSS · JavaScript

## Installation
```bash
git clone https://github.com/fady023/laravel_fady.git
cd laravel_fady
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate
php artisan serve
```
